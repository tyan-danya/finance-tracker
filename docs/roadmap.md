# Траты (SpendTracker) — дорожная карта

Приложение для учёта личных трат: Android, Kotlin + Compose, Room, полностью офлайн,
без аккаунтов и без сети. Все суммы — в копейках, валюта — рубль, интерфейс — русский.

---

## Сделано в v1.0

| Возможность | Детали |
|---|---|
| **Учёт трат** | Добавление, редактирование, удаление. Сумма, дата покупки, заметка, способ оплаты (карта / наличные / перевод / онлайн / другое) |
| **Категории и подкатегории** | 17 встроенных категорий с подкатегориями, свои категории с эмодзи-иконкой и цветом, архивирование, защита от удаления используемых |
| **Дата покупки** | Отдельно от даты внесения — можно вносить траты задним числом |
| **Статистика с графиками** | Кольцевая диаграмма по категориям, столбчатые графики, линейная динамика, топ-списки |
| **Фильтры по периоду** | День, месяц, год, произвольный диапазон, всё время; сравнение с предыдущим периодом |
| **Сводка «куда уходят деньги»** | Итог, число операций, средний чек, среднее в день, медиана, самая крупная трата, разбивка по категориям / подкатегориям / способам оплаты / дням недели |
| **Экспорт** | CSV (таблица), JSON (полные данные), Markdown-отчёт для ИИ-анализа — с шарингом через системное меню |
| **Тёмная тема** | Следует системной |

## Что дальше

Сгруппировано по приоритету. Оценки — грубые, в днях разработки.

### Приоритет 1 — ближайшее

| Задача | Зачем | Оценка |
|---|---|---|
| **Бюджеты и лимиты по категориям** | Главное, чего не хватает трекеру: не только «сколько потратил», но и «сколько осталось». Месячный лимит на категорию и общий, прогресс-бары в списке и статистике, предупреждение при превышении | 4–6 дн. |
| **Повторяющиеся траты** | Аренда, подписки, кредит — вносятся вручную каждый месяц. Шаблон + правило повторения + напоминание «подтвердить списание» | 3–5 дн. |
| **Поиск и теги** | При сотнях записей найти конкретную трату нечем. Поиск по заметке и сумме; свободные теги как второе измерение поверх категорий | 3–4 дн. |
| **Резервная копия** | Сейчас данные живут только в БД приложения: снёс — потерял. Локальный бэкап/восстановление одним файлом (шифрованный дамп через SAF) | 2–3 дн. |

### Приоритет 2 — заметно улучшает продукт

| Задача | Зачем | Оценка |
|---|---|---|
| **Быстрый ввод** | Плитка в шторке (Quick Settings Tile) и ярлыки на иконке приложения → сразу форма добавления. Снижает трение до пары секунд | 2–3 дн. |
| **Виджет на домашний экран** | Потрачено за месяц, остаток бюджета, кнопка «+». Glance/AppWidget | 3–5 дн. |
| **Импорт из банков** | Заливка истории выпиской вместо ручного ввода — снимает главный барьер входа. Подробная проработка: [`bank-integration.md`](bank-integration.md), Фаза 1 | 1.5–2 нед. |
| **Биометрический замок** | Финансовые данные под PIN/отпечатком, авто-блокировка при сворачивании. Логично делать вместе с шифрованием БД (см. `bank-integration.md`, §14.2) | 2–3 дн. |
| **Доходы и баланс** | Пока приложение видит только расход. Доходы дают ответ на «сколько остаётся» и норму сбережений. Требует расширения модели данных | 5–7 дн. |

### Приоритет 3 — по мере необходимости

| Задача | Зачем | Оценка |
|---|---|---|
| **Несколько валют** | Поле `currency` есть, но UI рублёвый. Нужны курсы (офлайн — вводимые вручную или на дату) и пересчёт в базовую валюту для статистики. Актуально для поездок | 5–8 дн. |
| **Автоматический учёт из уведомлений** | Траты появляются сами, пользователь только подтверждает. См. [`bank-integration.md`](bank-integration.md), Фаза 2 | 1.5–2 нед. |
| **Синхронизация между устройствами** | Самая дорогая задача: требует сервера или облачного хранилища, разрешения конфликтов и отказа от принципа «данные не покидают устройство». Минимальный вариант — синк через пользовательский Google Drive/файл | от 2 нед. |
| **Счета и карты** | Разделение трат по картам/наличным как отдельная сущность (сейчас есть только способ оплаты). Нужна для импорта из банков в любом случае | 3–4 дн. |
| **Сканирование чека (QR)** | Быстрый ввод суммы и даты по QR-коду кассового чека, локально и без сети. См. `bank-integration.md`, §8.2 | 2–3 дн. |

## Принципы, которые не меняем

- **Офлайн.** У приложения нет разрешения на интернет — и это самое сильное обещание
  приватности, которое можно дать. Любая фича, которая его нарушает (синхронизация,
  API банков, облачный OCR), включается только явным действием пользователя.
- **Деньги — только в копейках, `Long`.** Никаких `Double`.
- **Ничего не создаётся молча.** Автоматика (импорт, распознавание) предлагает — пользователь
  подтверждает. Статистика должна оставаться доверенной.
- **Интерфейс на русском.**

## Явно вне планов

- Просить у пользователя логин/пароль от интернет-банка — причины в
  [`bank-integration.md`](bank-integration.md), §15.
- Реклама, сторонняя аналитика, отправка данных трат куда-либо без запроса пользователя.
- Инвестиционные советы и любые рекомендации финансового характера.
